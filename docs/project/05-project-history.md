# היסטוריית הפרויקט ורטרוספקטיבה

זהו המסמך המרכזי. הוא מספר את הסיפור ההנדסי של `online-store` לפי סדר הזמן, כך שמי שפותח את
המאגר בעוד שנה יבין **למה הוא נראה כפי שהוא נראה**: לא רק מה נעשה, אלא מה הקדים מה, מה השתבש, ואיזו
החלטה הובילה לשלב הבא.

לכל שלב משמעותי יש אותם שדות: **למה**, **הקשר**, **בעיה**, **החלטה**, **מימוש**, **בדיקות**,
**תוצאה**, **לקחים**, **התלות הבאה**. שדה שאין לו ראיה כתוב `Not documented`. "לקחים" הם רק מה
שהפרויקט עצמו תיעד או מה שההיסטוריה מראה בבירור; הסקה מסומנת. הקודים (`MS3`, `M9.2` …) מוסברים ב-
[README](README.md#מינוח-שתי-מערכות-מספור), והמקורות (`[Git]`, `[PR #N]` …) שם גם כן.

### 4.2 T1: ביקורת, החלטות ותיוג (2026-10-04)

- **למה:** ההנחיה הראשונה דרשה להפוך את החנות ל-"modern, professional, production-quality portfolio
  project", ולא להמיר HTML ל-React מכני. בכל טכנולוגיה צריכה להיות סיבה ברורה.
- **הקשר:** העבודה חולקה לשני שלבים: **שלב ביקורת וארכיטקטורה** ללא שינוי במאגר, ורק אחרי אישור,
  מימוש. הביקורת השוותה React + Vite ל-Next.js והמליצה על Vite: הנתונים קובץ JSON סטטי, אין לוגיקת שרת,
  והאירוח הקיים הוא GitHub Pages. על Next.js נאמר "Not now. Only if we later choose a backend and need SEO".
  ההמלצה הסופית: שכבת נתונים מאחורי ממשק `services/`, כדי שאפשר יהיה לחבר API מאוחר יותר. ה-backend הוגדר
  כשער החלטה עם ברירת מחדל **לא**.
- **החלטות שאושרו (16:36):** Vite + React + TypeScript strict; React Router עם `BrowserRouter`;
  Tailwind עם RTL; Zustand עם `persist`; React Hook Form + Zod; Vitest, RTL ו-Playwright; ESLint ו-
  Prettier; CI; אימות דמו בלבד; **ללא backend בשלב זה**; ללא Redux, ללא TanStack Query, ללא ספריית
  i18n; הסרת Chatbase; shadcn/ui רק אם בדיקת ה-RTL תצדיק אותו.
- **החלטת ניקוי:** בעץ העבודה היו שני שינויים שלא נשמרו: נקודה-פסיק אחת ב-`style.css`, ו-`.gitignore`
  בן 482 שורות של תבנית Visual Studio/.NET. הבעלים הורה להשליך את שניהם, כדי שהמצב הישן יישאר "exactly as
  it exists in the published/main state", ושה-`.gitignore` החדש ייכתב מאפס ב-`MS1`, מצומצם לפרויקט

### 4.3 MS1: תשתית (PR #18, 2026-10-04 16:41 עד 16:59)

  CI).
- **בדיקות:** `lint`, `typecheck`, 2 בדיקות, `build`, `prettier --check`; fallback של Pages אומת
  בסימולציה מקומית. CI לא הורץ עוד.
- **תוצאה:** האתר ב-GitHub Pages הציג placeholder עד MS2, בידיעת הבעלים.
- **לקחים (מתועדים ב-PR):** ב-Windows עם נתיב שאינו ASCII, הפול `forks` של Vitest לא עלה, ולכן
