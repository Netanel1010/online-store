# תכנית הפרויקט בסגנון Jira

המסמך מדמה איך הפרויקט היה מתוכנן ב-Jira. הוא **לא** נוצר ב-Jira, ובפרויקט לא היה Jira. המזהים
הם מזהי תיעוד (ראו [README](README.md#מינוח-שתי-מערכות-מספור)); השמות הרשמיים (`M9.1`, "Milestone 2")
נשמרו כפי שהיו.

הכרטיסים נכתבו בדיעבד מתוך PRs, commits ומסמכים קיימים. קריטריוני הקבלה הם מה שהיה כתוב כיעד
(בתיאור ה-PR, בהנחיית העבודה או בתכנית המקורית), ולא מה שנוסח עכשיו. כשלא הוגדרו קריטריונים נפרדים
כתוב זאת.

## 1. מקרא הסטטוסים

| סטטוס         | משמעות                                        | ראיה                                   |
| ------------- | --------------------------------------------- | -------------------------------------- |
| `Planned`     | הוגדר כמשימה לפני הביצוע                      | מפת הדרכים או הנחיית עבודה (`[Notes]`) |
| `Implemented` | הקוד או התיעוד נכתב ונדחף                     | commits בענף                           |
| `Merged`      | מוזג ל-`main` דרך PR                          | `[Git]`, `[PR #N]`                     |
| `Verified`    | הבדיקות שבתיאור ה-PR רצו, וה-CI על `main` עבר | `[PR #N]`, `[CI]`                      |

בכרטיסים: ✓ = הושג, ✗ = לא הושג, ◐ = הושג חלקית או עם הסתייגות שמפורטת.
