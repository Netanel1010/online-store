# מסמך דרישות

מסמך זה מתאר מה נדרש מ-`online-store`, ומתי כל דרישה נכנסה. הוא נכתב בדיעבד, ולכן כל דרישה כאן
נשענת על ראיה: על תיאור ה-PR שהכניס אותה, על הקוד או על תיעוד קיים. לא נרשמה כאן דרישה שאין לה
ראיה.

קודי השלבים (`L0`, `MS3`, `M9.4` …) מוסברים ב-[README](README.md#מינוח-שתי-מערכות-מספור).

## 1. מטרה

לבנות חנות אינטרנט בעברית (RTL) למכירת רכיבי מחשב, שמדגימה בניית מערכת שלמה: חוויית קנייה בצד
הלקוח, API, מסד נתונים, חשבונות, עגלה והזמנות, בדיקות, פריסה ותיעוד.

הפרויקט התחיל כאתר סטטי של HTML, CSS ו-JavaScript שנבנה במסגרת לימודי הנדסת תוכנה. README של הגרסה
הראשונית: "developed during my first year (Semesters 2 & 3) of Software Engineering practical
studies" `[Git: legacy-v1]`. הוא נבנה מחדש ב-React ו-TypeScript, ובהמשך קיבל backend.

המטרה המוצהרת של שלב המודרניזציה, מתוך ההנחיה הראשונה `[Notes]`: להפוך את החנות ל"modern,
professional, production-quality portfolio project", ולא "convert HTML to React" פשוט. ההנחיה דורשת
שכל טכנולוגיה תהיה בעלת סיבה ברורה ("Every technology must have a clear reason for existing").

## 2. היקף

**בהיקף:** קטלוג מוצרים, חיפוש וסינון, עגלה, מועדפים, חשבונות אמיתיים בשרת, הזמנות דמו בשרת
(ללא תשלום), עמודי מידע, בדיקות אוטומטיות, CI/CD, אבטחה בסיסית של ה-API, נגישות, SEO ותיעוד.

**מחוץ להיקף:** ראו [סעיף 12](#12-מחוץ-להיקף).
