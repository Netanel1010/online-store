# תיעוד הפרויקט וההיסטוריה ההנדסית

אוסף המסמכים הזה מתאר את `Netanel1010/online-store` כפרויקט תוכנה: מה נדרש ממנו, איך תוכנן, מה חסם
את מה, איך בוצע, איך נבדק, ולמה הוא נראה היום כפי שהוא נראה. הוא נכתב אחרי שהעבודה הסתיימה, מתוך
ההיסטוריה שנשארה בפועל, ולכן הוא **תיעוד היסטורי** ולא תכנון מוקדם.

מה שהמסמכים האלה לא עושים: הם לא מחליפים את התיעוד הטכני של המערכת במצבה הנוכחי
([`../architecture.md`](../architecture.md), [`../deployment.md`](../deployment.md),
[`../runbook.md`](../runbook.md), [`../../server/README.md`](../../server/README.md)). הם מקשרים אליו
ואינם משכפלים אותו. כשיש סתירה בין מסמך כאן לבין הקוד, הקוד קובע.

תמונת המצב נלקחה מ-`main` ב-`a7826dd` (מיזוג PR #69), ב-2026-10-08. התיעוד נכנס ב-PR #70. הקובץ הקיים
היחיד שהוא נוגע בו הוא `docs/testing.md`, בתיקון גרסת ה-WCAG (2.0 עד 2.2).

## מקורות וסימון ראיות

כל עובדה בתיעוד הזה נשענת על אחד המקורות הבאים. סדר העדיפות כשיש סתירה הוא הסדר שבטבלה.

| סימון | מקור | הערה |
| --- | --- | --- |
| `[Git]` | היסטוריית Git של `origin/main` (commits, מיזוגים, תגיות, זמנים) | מקור סמכותי. הזמנים ב-`+03:00` כפי שנרשמו |
| `[Code]` / `[Config]` | הקוד וקבצי התצורה במצבם הנוכחי (`render.yaml`, `netlify.toml`, `ci.yml`, `package.json` …) | נבדקו מול `main` |
| `[PR #N]` | תיאור ה-PR ב-GitHub, זמני היצירה והמיזוג, ובדיקות ה-review | נשלפו מ-API הציבורי של GitHub. הזמנים שם ב-UTC (שלוש שעות פחות מ-`+03:00`) |
| `[CI]` | תוצאות הרצת workflows על `main` | נשלפו מ-API הציבורי של GitHub |
| `[Docs]` | התיעוד שכבר קיים במאגר (`docs/`, `README.md`, ADRs) | חלק מה-ADRs רטרוספקטיביים, ראו את ההסבר ב-[`../adr/README.md`](../adr/README.md) |
| `[Notes]` | הערות תכנון: הנחיות העבודה שניתנו בסשנים של Claude Code והתשובות שהתקבלו עליהן | **לא נמצאות במאגר** ולכן אי אפשר לאמת אותן ממנו. שימשו רק לשחזור ההקשר וההחלטות. מקור בעדיפות הנמוכה ביותר |

## מקרא סטטוסים

| סטטוס | משמעות בתיעוד הזה | הראיה |
| --- | --- | --- |
| `Planned` | הוגדר כמשימה, לפני שבוצע | מפת הדרכים או הנחיית העבודה (`[Notes]`) |
| `Implemented` | הקוד או התיעוד נכתב ונדחף לענף | commits בענף (`[Git]`) |
| `Merged` | מוזג ל-`main` דרך PR | מיזוג ב-`[Git]` ו-`[PR #N]` |
| `Verified` | נבדק: הבדיקות שבתיאור ה-PR רצו, ו-CI על `main` עבר | `[PR #N]` ו-`[CI]` |

`Verified` אינו אומר "ללא תקלות". כשבדיקה אחרי המיזוג נכשלה, זה מצוין (ראו
[`05-project-history.md`](05-project-history.md)).

## זמנים

- `[Git]` מציג זמנים מקומיים (`+03:00`), ו-`[PR #N]` ו-`[CI]` ב-UTC. בטבלאות כתוב איזה מהם.
- זמן "ענף" הוא מההתחייבות הראשונה בענף עד המיזוג. הוא **גבול תחתון** של העבודה: הביקורת, התכנון
  וההבהרות שלפני ה-commit הראשון לא נספרים.

## מה לא ניתן להוכיח

הרשימה המאוחדת של הפרטים שאין להם מקור. כל אחד מהם מופיע גם במסמך שבו הוא רלוונטי.

| פרט | למה לא ידוע |
| --- | --- |
| משך עבודה מתוכנן לפרויקט או למפת הדרכים | לא נמצא בשום מקור. `Planned duration: Not formally documented.` |
| שעות עבודה בפועל | יש רק חותמות זמן של commits ו-PRs, לא רישום שעות |
| הגנת הענף `main` (branch protection, required checks) | הגדרות מאגר שדורשות הרשאת ניהול. ה-API הציבורי החזיר `401`. PR #28 מציין שזו הגדרת מאגר שלא נעשתה בו |
| תוצאות CodeQL ו-secret scanning כרשימה | דורשות הרשאה. נשענים רק על מה שנאמר ב-PRs |
| מועד יצירת שירות ה-Render, אשכול ה-Atlas ואתר ה-Netlify | נוצרו בלוחות הבקרה של השירותים, לא ב-Git |
| תוכנית ה-Atlas (tier) ושיטות הגיבוי | לא אומתו. [`../runbook.md`](../runbook.md) מציין זאת כפער |
| מה אבד ב"i lost 50 commits after kipur" (`f634918`) | רק הודעת ה-commit קיימת |
| למה PR #54 (שדרוג TypeScript ל-7.0.2) נסגר בלי מיזוג | נסגר ב-2026-10-07 12:29 UTC. הסיבה לא נרשמה. הגרסה במאגר נשארה `^6.0.3` |
| הענף שממנו נבנה הפריסה הראשונה של Netlify | התצורה שדווחה הייתה `main`, ו-`netlify.toml` נכנס ל-`main` רק במיזוג #69 (06:20), אחרי שהבעלים דיווח על פריסה מוצלחת (06:07) |
| זהות החשבון `NETANEL576` כבעל הפרויקט | אינה ניתנת לאימות ממקורות GitHub ציבוריים בלבד. מתועד כחשבון GitHub נוסף שהיה מעורב באישור PRs (ראו [`08-team-and-time.md`](08-team-and-time.md)) |
| האם `smoke.yml` הורץ אי פעם | נכון לשליפה ל-API לא היו הרצות שלו |
| האם כל PR נפתח ידנית או דרך כלי | כל ה-PRs רשומים תחת `Netanel1010`. ל-PRs המאוחרים יש עדות שהבעלים פתח אותם מקישור השוואה; לשאר Not documented |
